# Hardware Overview

Project del Luna is intentionally designed with a minimal hardware architecture.

Instead of integrating numerous sensors,
the system focuses on three essential components:

- STM32U575
- ST25DV64KC NFC
- Waveshare 7.3-inch Spectra 6 E-paper

Together, these components provide:

- Ultra-low-power operation
- Smartphone NFC interaction
- Paper-like reading experience
- Long-term memory preservation
