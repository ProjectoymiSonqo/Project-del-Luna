# Project Del Luna

An embedded digital Goshuin book designed to preserve travel memories through NFC and E-paper technology.

---

## Motivation

During the final stage of my world journey, I spent time visiting shrines across Japan.

Traditional Goshuin books preserve memories in a beautiful and meaningful way. Rather than replacing this tradition, Project Del Luna explores how embedded systems can complement it.

The project combines embedded firmware, NFC, E-paper, and a companion mobile application to create a digital experience that respects the culture while expanding the possibilities of preserving travel memories.

---

## Features

- Electronic Goshuin book
- NFC synchronization
- E-paper display
- Shrine database
- GPS-assisted shrine discovery
- Companion mobile application
- Low-power embedded design
- Modular system architecture
